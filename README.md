# Dynamic Touch Sampling Rate

动态触感采样率调节模块 — C语言守护进程 + 液态玻璃App可视化管理，适配 **红米 K90 Max (codename: prague / 型号: 2604FRK1EC)**。

## 功能特性

- **动态采样率调节**：根据前台 App 自动切换 120Hz / 240Hz / 480Hz
- **应用级规则**：每个 App 可独立配置采样率，打开即匹配
- **应用分类管理**：系统应用 / 第三方应用分开显示，可视化选择配置
- **真实应用图标**：读取系统应用图标，列表展示真实图标
- **液态玻璃 App**：简约液态玻璃设计，4个功能页面（状态/应用规则/全局配置/日志）
- **常驻通知栏**：通知栏显示当前应用+采样率，一键切换省电/平衡/高性能
- **Root 权限控制**：通过 Root 权限直接控制采样率，无需无障碍服务
- **进程保护**：Root 降低 oom_adj，防止后台进程被系统杀死
- **触摸固件优化**：bind mount 替换 `prague_gtp_thp_config.ini`，支持 135/240/480Hz 三档
- **完整日志记录**：带自动轮转（256KB），方便排查异常
- **低耗电设计**：熄屏自动降频（15s）、亮屏才检测前台应用、条件写入 sysfs
- **低内存**：C语言单线程、固定缓冲区、零 malloc、静态编译约 93KB
- **不挂载 system 分区**：仅 bind `/odm/firmware/` 单个文件，安全可逆
- **最高采样率 480Hz**

## 安装

1. 下载 `DynamicTouchSampling-v1.0.2.zip`
2. KernelSU / Magisk 中刷入
3. 重启设备
4. 打开「触感控制」App，授予 Root 权限

> 模块已内含预编译 aarch64 静态二进制（bin/touchd）和配套 App（apk/TouchControl.apk），可直接刷入使用。

## 使用

### App 功能页面

1. **状态**：当前采样率、模式切换（自动/省电/平衡/高性能）、运行状态、守护进程控制
2. **应用规则**：搜索应用、分类筛选（全部/第三方/系统/已配置）、点击应用配置采样率
3. **全局配置**：三档采样率设置、轮询间隔、低电量阈值、触摸节点扫描
4. **日志**：实时查看守护进程日志、刷新、清空

### 通知栏快捷操作

- 常驻通知显示当前应用和采样率
- 三个快捷按钮：省电 / 平衡 / 高性能
- 点击通知打开 App

### 命令行控制 (终端)

```bash
touchd --status      # 查看状态
touchd --mode high   # 强制高性能
touchd --mode auto   # 恢复自动
touchd --log         # 查看日志
```

## 配置文件

运行时目录：`/data/adb/dynamic_touch_sampling/`

| 文件 | 说明 |
|------|------|
| `config.conf` | 全局配置（采样率档位、轮询间隔、低电量阈值） |
| `app_profiles.conf` | 应用规则（包名=模式） |
| `log/touchd.log` | 运行日志（256KB 自动轮转） |
| `device_info` | 设备信息 |

## 卸载

卸载模块 + 重启设备 = 完全恢复原始状态。

卸载时会自动：
- 停止守护进程
- 解除固件配置 bind mount
- 卸载配套 App
- 备份配置文件到 /sdcard/

## 技术细节

- **守护进程**：C 语言单线程，静态编译 aarch64，约 93KB
- **App**：Android 原生开发，液态玻璃设计，约 6MB
- **通信方式**：App 通过 Root 权限执行 touchd 命令和读写配置文件
- **前台应用检测**：Root 轮询 `dumpsys activity`（1.5秒间隔）
- **进程保护**：Root 修改 `/proc/<pid>/oom_score_adj` 为 -1000
